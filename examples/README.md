# Examples

Demonstrations of scitex-dev's main features.

## Prerequisites

```bash
pip install scitex-dev
```

## Examples

| # | Script | Description |
|---|--------|-------------|
| 01 | `01_unified_search.py` | Search across APIs, CLI, MCP tools, and documentation |
| 02 | `02_version_management.py` | Track and compare versions across the ecosystem |
| 03 | `03_docs_aggregation.py` | Aggregate and search documentation from all packages |

## Running

Run all examples:

```bash
bash 00_run_all.sh
```

Or run individually:

```bash
python 01_unified_search.py
```

Each example saves output artifacts to a corresponding `*_out/` directory.
